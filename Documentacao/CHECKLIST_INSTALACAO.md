# Checklist rápido

Desenvolvido por Daniel Moreira · Instagram `@moreiraprodux`

Use esta lista para conferir se está tudo pronto.

## Instalação

- [ ] Extraí o `.zip`.
- [ ] Abri a pasta `Hermes Easy Installer`.
- [ ] Rodei o instalador correto para meu sistema:
  - Windows: `INSTALAR_WINDOWS.bat`
  - macOS: `INSTALAR_MAC.command`
  - Linux/WSL2/Termux: `INSTALAR_LINUX.sh`
- [ ] Abri um terminal novo depois da instalação.
- [ ] Rodei `hermes`.
- [ ] O Hermes respondeu no terminal.

## Modelo/API key

- [ ] Rodei `hermes model`.
- [ ] Escolhi um provedor.
- [ ] Colei minha API key ou fiz login.
- [ ] Testei uma conversa simples.

## Telegram

- [ ] Abri `@BotFather`.
- [ ] Rodei `/newbot`.
- [ ] Criei nome e username terminado em `bot`.
- [ ] Copiei o token do bot.
- [ ] Descobri meu ID numérico com o bot auxiliar `@userinfobot` ou `@get_id_bot`.
- [ ] Rodei `hermes gateway setup`.
- [ ] Escolhi Telegram.
- [ ] Colei o token.
- [ ] Colei meu ID numérico como usuário autorizado.
- [ ] Iniciei o gateway.
- [ ] Enviei `/start` para meu bot.
- [ ] O bot respondeu.

## Segurança

- [ ] Não publiquei meu token.
- [ ] Não coloquei API key em repositório público.
- [ ] Autorizei só meu próprio Telegram User ID.
