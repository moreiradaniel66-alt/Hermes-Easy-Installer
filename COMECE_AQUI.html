Hermes Easy Installer

Instale o Hermes Agent sem decorar comandos.

Escolha seu sistema, clique para iniciar o instalador e siga os próximos passos na tela. Tudo aqui é HTML puro: não precisa de Node, npm, Vite ou servidor local.

Aviso honesto: esta página é um guia visual. Para executar de verdade, use o instalador do seu sistema na pasta principal. No Windows, o instalador abre um mini-app nativo com botão real de instalação.

Depois que terminar

    Configurar modelo ou API key

    O Hermes precisa de um provedor/modelo para responder. O instalador normalmente abre essa etapa sozinho, mas você pode fazer manualmente.

    1. Abrir configuração do modelo

    1

    No Windows: abra o PowerShell. No macOS/Linux: abra o Terminal.

    2

    Clique em Copiar comando, cole no PowerShell/Terminal e pressione Enter.

    3

    Quando o assistente abrir, escolha seu provedor/modelo e cole sua API key se ele pedir.

    hermes model

    2. Testar antes do Telegram

    No mesmo PowerShell/Terminal, cole este comando e pressione Enter:

    hermes

    Quando a conversa abrir, envie esta mensagem de teste:

    Oi, Hermes. Responda apenas: instalação funcionando.

    Só clique em Hermes respondeu, configurar Telegram depois que ele responder essa mensagem.

    Conectar ao Telegram

    Faça esta parte só depois que o Hermes respondeu no terminal.

    1. Crie o bot

    1. Abra o Telegram e procure por @BotFather.
    2. Envie /newbot.
    3. Escolha um nome, por exemplo Meu Hermes Pessoal.
    4. Escolha um username terminado em bot, por exemplo meu_hermes_bot.
    5. Copie o token que o BotFather entregar.

    Guarde esse token como senha. Não publique em grupo, print ou repositório.

    2. Pegue seu ID numérico

    No Telegram, procure pelo bot auxiliar @userinfobot. Ele não é o seu bot Hermes; ele serve só para mostrar seu ID numérico. Envie /start e copie o número. Se não funcionar, tente @get_id_bot.

    3. Configure o gateway

    No Windows: abra o PowerShell. No macOS/Linux: abra o Terminal. Depois copie o comando abaixo, cole lá e pressione Enter.

    hermes gateway setup

    Quando o assistente abrir, escolha Telegram, cole o token do BotFather e depois cole seu ID numérico como usuário autorizado.

    4. Inicie e teste

    No mesmo PowerShell/Terminal, copie o comando abaixo, cole e pressione Enter.

    hermes gateway start

    Se não funcionar no seu sistema, tente:

    hermes gateway
hermes gateway run

    Abra seu bot no Telegram, envie /start e depois:

    Oi, Hermes. Você está conectado?
