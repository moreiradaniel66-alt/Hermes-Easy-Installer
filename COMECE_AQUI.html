Hermes Web Dashboard (Painel de Controle)

Um painel visual completo no navegador para gerenciar seu agente sem precisar do terminal.

O que o Web Dashboard oferece?

  • Histórico de Sessões: Navegue pelas conversas anteriores de forma organizada.
  • Editor de Memórias & Persona: Edite o SOUL.md, variáveis .env e configurações com um clique.
  • Habilidades & Ferramentas MCP: Gerencie servidores de ferramentas e automações agendadas (cron).
  • Métricas & Tokens: Gráficos em tempo real de consumo e latência.
  • Chat Web Integrado: Converse diretamente pela interface do navegador.

Como Iniciar o Dashboard em 1 Clique

No Windows, você pode iniciar pelo menu do INSTALAR_WINDOWS.bat escolhendo a opção 3, ou digitar no terminal:

Terminal
$hermes dashboard

O servidor subirá em http://127.0.0.1:9119 e abrirá automaticamente no seu navegador padrão.

Controle Total do Operador: O dashboard roda 100% local no seu computador na porta 9119. Nenhum dado do seu agente é transmitido para servidores de terceiros.

Configuração do Agente & Provedor LLM

O Hermes Agent precisa de uma chave de inteligência artificial para pensar e agir. A Nous Research simplificou o processo no assistente unificado hermes setup.

1

Execute o Assistente de Configuração

Abra um novo terminal (PowerShell no Windows ou Terminal no Mac/Linux) e execute:

Terminal
$hermes setup

O assistente interativo vai perguntar qual provedor você quer usar (OpenRouter, OpenAI, Anthropic, MiniMax ou modelo local) e solicitar sua chave de API.

2

Alternância Rápida de Modelos (Opcional)

Se você já configurou e deseja apenas trocar de modelo ou testar outro provedor a qualquer momento:

Terminal
$hermes model
3

Fazer o Primeiro Teste no Terminal

Inicie a conversa direta com seu agente no terminal:

Terminal
$hermes

Quando ele responder, envie: Oi, Hermes. Responda apenas: sistema funcionando.

Recomendação Moreira Labs: O OpenRouter é o provedor mais flexível, permitindo alternar entre os modelos oficiais Nous Hermes 3, Claude 3.5 Sonnet, GPT-4o e Gemini com uma única chave.

Conectar ao Telegram & Aplicativos de Mensagens

O Hermes possui um Gateway Multicanal integrado. Você pode conversar com ele no seu celular pelo Telegram como se fosse um contato pessoal.

1

Crie seu Bot Oficial no Telegram

1. No aplicativo do Telegram, busque por @BotFather.
2. Envie o comando /newbot.
3. Escolha o nome de exibição (ex.: Hermes Moreira Labs).
4. Escolha um username terminando em bot (ex.: hermes_moreira_bot).
5. Copie o Token HTTP API fornecido pelo BotFather.

2

Descubra o seu ID Numérico de Segurança

Para garantir que apenas você possa comandar seu agente e ninguém mais tenha acesso, o Hermes exige o seu ID numérico.
No Telegram, abra o bot auxiliar @userinfobot, dê /start e copie o número exibido em Id.

3

Configure o Gateway no Terminal

Execute o assistente de conexão:

Terminal
$hermes gateway setup

Selecione Telegram, cole o token do BotFather e depois insira o seu ID numérico.

4

Inicie o Gateway de Comunicação

Inicie o serviço de escuta em segundo plano:

Terminal
$hermes gateway start

Pronto! Agora abra o Telegram e envie uma mensagem para o seu bot. Ele responderá imediatamente!

Diagnóstico, Saúde & Solução de Problemas

Se algo não funcionar como esperado, o Hermes possui ferramentas automáticas de verificação e reparo.

Hermes Doctor (Diagnóstico de Saúde)

Verifica dependências, ambiente Python `uv`, chaves de API e permissões:

Terminal
$hermes doctor

Status do Gateway Telegram

Verifica se o bot está conectado e escutando mensagens:

Terminal
$hermes gateway status

Dúvidas Frequentes

?

O comando "hermes" não é reconhecido no terminal

Isso acontece quando o terminal estava aberto antes da instalação. Basta fechar todas as janelas do terminal e abrir uma nova.

?

Como manter o Telegram rodando 24 horas?

O comando hermes gateway start roda em background no Windows e Linux. Se o seu ambiente não tiver suporte a daemons (ex.: WSL2), rode hermes gateway run mantendo o terminal ativo.

?

Onde ficam salvas as conversas e memórias?

Todos os dados do Hermes ficam salvos em ~/.hermes/ (ou %LOCALAPPDATA%\hermes\ no Windows). Você pode fazer backup dessa pasta para manter todas as memórias e skills aprendidas.
